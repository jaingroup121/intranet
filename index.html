About this Intranet
A unified front door to every department, project and document.

The Jain Group Intranet is the central navigator for departments, projects and shared documents at Jain Group head office. It pulls together resources from Accounts & Finance, Audit/ERP/MIS, HR/Admin/PR, IT, Legal, Management, Marketing, Operations and Stores & Purchase into a single, searchable Solution Navigator.

📁 How resources are organised

Every link visible on this intranet maps directly into the G:\Jain HO Web shared folder, the FarVision ERP, or a Dropbox / web URL the IT department maintains. Login-protected sections continue to use the existing PHP login screens — this intranet is purely a unified front door, it does not replace those access controls.

⚙️ Need to add or update a link?

Open this file in any text editor and edit the DATA array at the bottom of the <script> section — it drives the dashboard cards, every department panel and the Quick Reference table. A single edit propagates everywhere.
